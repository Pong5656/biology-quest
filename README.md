# 🧬 BIO QUEST — ผจญภัยชีววิทยา 8-Bit

เกมเรียนชีววิทยา ระดับชั้นมัธยมปลาย (ตามหลักสูตร สสวท.) สไตล์เกมคอนโซลยุค 8-bit (NES) — สอนเป็นแผนที่โลก 25 บท แต่ละบทเป็นภารกิจ 4 ด่าน เรียงลำดับปลดล็อกทีละขั้น พร้อมพิชิตบอสข้อสอบท้ายบท!

## 📚 เนื้อหา (25 บท · ชีววิทยา ม.ปลาย)

ระบบนิเวศและสิ่งมีชีวิต · เซลล์ · การลำเลียงสาร · ระบบประสาท/ต่อมไร้ท่อ · การตอบสนอง · ระบบภูมิคุ้มกัน · ระบบหายใจ/ไหลเวียนโลหิต · ระบบย่อยอาหารและการขับถ่าย · การเคลื่อนที่ของสิ่งมีชีวิต · การสืบพันธุ์ · **การสังเคราะห์ด้วยแสง** · การหายใจระดับเซลล์ · การแบ่งเซลล์และวงจรเซลล์ · การถ่ายทอดลักษณะทางพันธุกรรม · โครโมโซมและสารพันธุกรรม · เทคโนโลยีชีวภาพ · วิวัฒนาการ · ความหลากหลายทางชีวภาพ · อนุกรมวิธาน · และอื่นๆ ครบหลักสูตร

> แต่ละบทเริ่มต้นจาก `src/data/chapters/ch{บท}.ts` — แก้เนื้อหาได้โดยตรง เพิ่มบทใหม่ได้จาก `_template.ts`

## 🛠️ เทคโนโลยี

- Next.js 16 (App Router) + React 19 + TypeScript
- Tailwind CSS v4 + **NES.css** ธีม 8-bit (ฟอนต์ Press Start 2P + Prompt)
- เกม/อนิเมชัน เขียนด้วยพิกเซลอาร์ต (`src/game/engine.ts`, `sprites.ts`) + Web Audio (sfx)
- บันทึกความคืบหน้าผ่าน **API + PostgreSQL (drizzle + pg)** — แต่ Deploy ได้ **โดยไม่ต้องมีฐานข้อมูล** (จะเล่นต่อได้ในเครื่องแบบพื้นฐาน และพร้อมต่อยอดเมื่อตั้ง `DATABASE_URL`)

## 🚀 เริ่มพัฒนา

```bash
npm install
npm run dev        # dev server ที่ http://localhost:3000
npm run build      # build production
npm run lint       # eslint
npm run typecheck  # tsc --noEmit
```

## ☁️ Deploy บน Vercel

1. push โค้ดขึ้น GitHub
2. เปิด [vercel.com/new](https://vercel.com/new) → **Add New Project** → import repo → **Deploy**
3. (แนะนำ) เปิดใช้การเซฟข้ามเครื่อง:
   - เพิ่ม **Neon / Vercel Postgres** → คัดลอก URL ตั้งค่า Env `DATABASE_URL`
   - รัน `npx drizzle-kit push` (สร้างตาราง `players` + `chapter_progress`)
   - ไม่ตั้งก็ได้ — แอปยังเล่นได้ครบทุกบท แต่ความคืบหน้าจะไม่เซฟข้ามเครื่อง

> API `/api/health`, `/api/player`, `/api/progress` ตอบ `503 db=not-configured` เมื่อไม่มี `DATABASE_URL` — client ถูกออกแบบให้เล่นต่อได้แบบออฟไลน์
