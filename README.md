# 🧬 BIO QUEST — ผจญภัยชีววิทยา 8-Bit

เกมเรียนรู้**ชีววิทยา ม.ปลาย (ม.4–ม.6)** สไตล์ 8-Bit RPG ทุกบทเรียนเป็นด่านบนแผนที่โลก 3 ยูนิต — เนื้อหาอิงหลักสูตร สสวท. ทั้งหมดภาษาไทย
พร้อมระบบสลับภาษา **TH / EN** และการเซฟความคืบหน้าข้ามเครื่อง (ตัวเลือก)

## 🗺️ โลกและเนื้อหา (25 บท / 6 เล่ม)

| World | ชั้น | เล่ม | เนื้อหา |
|---|---|---|---|
| 1 | ม.4 | 1–2 | การศึกษาชีววิทยา · เคมีชีวโมเลกุล · เซลล์ (บท 1–10) |
| 2 | ม.5 | 3–4 | Photosynthesis (บทต้นแบบ) · ระบบย่อยอาหาร · ระบบหายใจ · ระบบไหลเวียนเลือด ฯลฯ (บท 11–18) |
| 3 | ม.6 | 5–6 | ระบบประสาท · ระบบต่อมไร้ท่อ · ภูมิคุ้มกัน · พันธุศาสตร์ · วิวัฒนาการ นิเวศวิทยา (บท 19–25) |

> เนื้อหาบทอยู่ที่ `src/data/chapters/ch01–ch25.ts` — แต่ละบทครบ 4 Section ดู `_template.ts` สำหรับเพิ่มบทใหม่

## 🎮 รูปแบบการเล่นต่อบท (4 Section — ปลดล็อกทีละขั้น)

| # | Section | รายละเอียด |
|---|---|---|
| 1 | 📜 **สรุปเนื้อหา** | การ์ดสรุปเนื้อหาสำคัญของบท |
| 2 | 📖 **เรียนทีละสไลด์** | สไลด์ทฤษฎีจับมือสอน พร้อมคีย์เวิร์ด |
| 3 | 🔑 **มินิเกมคีย์เวิร์ด** | จับคู่คำศัพท์สำคัญกับความหมาย |
| 4 | 👾 **บอสข้อสอบจริง** | เกมมาริโออาร์เคด + ข้อสอบ 20 ข้อ (4 ตัวเลือก, มีคำใบ้แลกเหรียญ) — ชนะบอส = ผ่านบท |

ข้ามด่านที่ยังไม่ปลดล็อก = เตือน ต้องทำ Section ก่อนหน้าจนผ่านก่อน (ค่าความคืบหน้าไม่มีวันลดลง)

## ✨ ฟีเจอร์

- 🌍 **World Map 3D-ish 8-bit** — 3 World × 6 เล่ม × 25 บท (COMING SOON สำหรับบทที่ยังไม่เปิด)
- 🕹️ **เกมมาริโอ 8-Bit ในด่านบอส** (`src/game/engine.ts`) — เดิน/กระโดดด้วย **คีย์บอร์ด + ปุ่มแตะจอ** (`TouchPad.tsx`) รองรับมือถือ
- 💬 **สลับภาษา TH/EN** — UI/ชื่อบท/เล่ม แปลครบ (`src/lib/i18n.tsx` + `src/data/en/`)
- 🪙 **ระบบเหรียญ** — เก็บจากเกม แลกคำใบ้ในบอสข้อสอบ ตั้งชื่อผู้เล่นได้
- 💾 **เซฟความคืบหน้า** — playerId สร้างอัตโนมัติ (localStorage) → sync ฐานข้อมูลเมื่อตั้ง `DATABASE_URL` (ค่าไม่มีวันลดลง)
- 🔊 **เสียง 8-Bit** — Web Audio API (ไม่ต้องโหลดไฟล์เสียง)

## 🛠️ เทคโนโลยี

- Next.js 16 (App Router) + React 19 + TypeScript + Tailwind CSS v4
- Canvas API (`src/game/`) + framer-less เกมลูปใช้ rAF
- Drizzle ORM + PostgreSQL (ตัวเลือก — เฉพาะเซฟข้ามเครื่อง)
